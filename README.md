# ГадВулик (gadvulyc-sr)

Навчальний MVP каталогу майстрів Гадяча та району. Користувач знаходить майстра, оцінює вартість робіт у калькуляторі й залишає заявку через форму контактів.

> Демонстраційний проєкт: імена майстрів, ціни та відгуки вигадані.

**Сайт:** https://gadvulyc-sr.vercel.app

## Можливості

- 5 сторінок: Головна, Майстри, Калькулятор, Про проєкт, Контакти.
- **Каталог майстрів**: пошук, фільтр за категорією та рейтингом, сортування, модальне вікно з деталями. Параметри фільтра зберігаються в URL.
- **Калькулятор вартості робіт**: послуга, обсяг, терміновість, виїзд, матеріали. Перевіряє порожнє значення, нуль, від'ємні й нечислові значення, перевищення максимуму, дробові значення для штучних одиниць, збій завантаження даних.
- **Форма контактів**: перевірка імені, email і телефону регулярними виразами, маска телефону `+380 (XX) XXX-XX-XX`, лічильник символів.
- Темна та світла тема (Tailwind `dark:`), вибір зберігається в `localStorage`.
- Дані каталогу в `data/data.json`, завантаження через `fetch` / `async-await`.
- Swiper (відгуки) і GLightbox (галерея) підключені через CDN.
- Open Graph та Twitter Card, `sitemap.xml`, `robots.txt`, Vercel Web Analytics.

## Технології

HTML5 (семантична розмітка), Tailwind CSS 3, JavaScript (ES2020, без фреймворків), Swiper 14, GLightbox 3, Vercel.

## Структура

```
index.html, masters.html, calculator.html, about.html, contact.html
css/input.css      вихідний файл Tailwind
css/styles.css     зібраний і мінімізований CSS (комітиться)
js/                common.js (тема, меню, fetch), home.js, masters.js, calculator.js, contact.js, about.js
data/data.json     майстри, послуги, ціни, відгуки
img/               логотип, SVG-ілюстрації, OG-обкладинка
```

## Запуск

```bash
npm install
npm run build:css   # зібрати Tailwind CSS
npm start           # локальний сервер (npx serve .)
```

Відкрийте адресу, яку покаже `serve` (зазвичай http://localhost:3000). Сторінки не відкриються через `file://`, бо `fetch` потребує HTTP.

Після зміни класів Tailwind у `*.html` або `js/*.js` перезберіть CSS: `npm run build:css`.
